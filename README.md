## 🛠️ Quick Start Guide

To run or explore any of these projects locally:

### Step 1: Clone the repository
```bash
git clone https://github.com/OnTheHitlist/OnTheHitlist.git
cd OnTheHitlist
```

### Step 2: Switch to the project's branch
For example, to run the **FIFA World Cup 2026 Predictor**:
```bash
git checkout fifa-wc-predictor
```
To run the **NSE/BSE Paper Trader**:
```bash
git checkout nse-bse-paper-trader
```

### Step 3: Run the project
Follow the dedicated `README.md` or `DOCS.html` instructions inside that branch to run the project.
