## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/OnTheHitlist/OnTheHitlist.git
cd OnTheHitlist
```

### 2. Install dependencies
```bash
pip install numpy matplotlib
```
> **Anaconda users:** all dependencies are already bundled — skip this step.

### 3. Run the model (~25 seconds)
```bash
python run_predictor.py --sims 50000
```

### 4. Open the dashboard
```bash
# Windows
start web/index.html

# macOS
open web/index.html

# Linux
xdg-open web/index.html
```

### 5. *(Optional)* Explore the Jupyter notebook
```bash
jupyter notebook wc2026_analysis.ipynb
```

## 🧮 Methodology

| Component | Details |
|-----------|---------|
| **Historical Data** | 900+ FIFA WC matches, 1930–2022 |
| **ELO System** | Dynamic ratings with K-factor by stage (Group: 30, Final: 60) |
| **Recency Weighting** | Post-2014 matches weighted 2×, post-2002 weighted 1.5× |
| **Goal Difference Bonus** | Logarithmic multiplier on K-factor |
| **Draw Model** | Dixon-Coles Gaussian decay (base 24% draw rate) |
| **Goal Simulation** | Poisson sampling from ELO-derived λ |
| **Knockout Stage** | ELO-weighted probability + penalty shootouts |
| **Simulations** | 50,000 full tournaments (Monte Carlo) |

### How a simulation works
1. Simulate all round-robin group matches via Poisson goal sampling
2. Rank teams: points → goal difference → goals scored → ELO
3. Top 2 per group + 8 best 3rd-place teams advance (32 total)
4. Simulate R32 → R16 → QF → SF → Final (no draws in knockouts)
5. Record stage reached for every team
6. After 50,000 runs → frequency = probability
