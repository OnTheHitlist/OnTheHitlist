🌐 Section 1

Overview

This project predicts the probability of each of the 48 qualified teams winning the FIFA World Cup 2026, using a combination of:

  • Historical ELO ratings — computed from all 900+ WC matches since 1930
  • Recent form adjustments — boosting teams based on 2022–2025 performance
  • Monte Carlo simulation — running 50,000 complete tournaments
  • Poisson goal model — for realistic group-stage scorelines

Results are displayed in a beautiful interactive web dashboard and a Jupyter notebook with detailed matplotlib charts.

Quick Start

Get up and running in under 2 minutes with these three steps:

1
Clone the repo & open a terminal
Clone from GitHub, then open a terminal (PowerShell, Anaconda Prompt, or bash) inside the project folder:
# Clone the repository git clone https://github.com/OnTheHitlist/OnTheHitlist.git # Navigate into the project folder cd OnTheHitlist
2
Run the prediction model
This runs 50,000 tournament simulations and saves the results. Takes about 25–30 seconds.
# Works on Windows, macOS, and Linux: python run_predictor.py --sims 50000 # If 'python' is not found, try: python3 run_predictor.py --sims 50000
✅
Expected output You should see the ELO top 15 table printed, then progress like 10,000 / 50,000 complete..., then the final championship table.
3
Open the dashboard
Open the web dashboard in any browser — no server needed, just a local file.
# Windows — double-click web/index.html, or: start web\index.html # macOS: open web/index.html # Linux: xdg-open web/index.html
⚠️
Run step 2 first! The dashboard reads from output/predictions.json. If you open it before running the model, you'll see an error screen. Just run step 2 then refresh.

How It Works

ELO Rating System

Every team starts with a base ELO of 1500. After each historical WC match, ratings are updated using:

New Rating = Old Rating + K × GoalDiffBonus × (Actual - Expected) Expected = 1 / (1 + 10^(-(ELO_A - ELO_B) / 400))
ParameterValueRationale
K-factor (Group)30Group matches matter less
K-factor (Final)60Finals have highest impact
Recency weight (2014+)2×Recent form matters more
Recency weight (2002+)1.5×Modern football era
Goal diff bonuslog(GD+1)×0.15+1Rewards dominant wins

Draw Probability Model

Football has frequent draws. We use a Gaussian decay model:

P(Draw) = 0.24 × exp(-0.0012 × ELO_diff²) # Close match (ELO diff = 0): P(Draw) ≈ 24% # Big mismatch (diff = 300): P(Draw) ≈ 5%

Monte Carlo Tournament Simulation

Each simulation runs one complete 2026 World Cup:

  1. Simulate all 6 round-robin matches per group using Poisson goal sampling
  2. Rank teams by points → goal difference → goals scored → ELO
  3. Select top 2 from each group + 8 best 3rd-place teams = 32 advance
  4. Simulate R32 → R16 → QF → SF → Final (knockout, no draws)
  5. Record which stage each team reaches

After 50,000 runs, the frequency of each outcome becomes the probability.

🔬
Limitations to be aware of The model is purely historical — it doesn't account for current squad injuries, tactical setups, individual player quality (e.g., Mbappé, Messi), home/neutral ground advantage, or weather conditions. Use it as a statistical baseline, not a betting guide.

Frequently Asked Questions

The dashboard shows "Predictions Not Found" — what do I do? ▼
You need to run the model first to generate output/predictions.json. Open a terminal, navigate to the project folder, and run:

& "C:\Users\shant\anaconda3\python.exe" run_predictor.py

Then refresh the browser page.
python is not recognized — how do I fix this? ▼
Python may not be on your system PATH. Try these options:

Option A: Use python3 instead of python (common on macOS/Linux).

Option B (Windows + Anaconda): Open Anaconda Prompt from the Start menu — Python works there automatically.

Option C: Reinstall Python from python.org and tick "Add Python to PATH" during setup.
Can I change the number of simulations? ▼
Yes! Use the --sims flag:

• --sims 5000 — fast, ~3 seconds, less accurate
• --sims 50000 — recommended, ~25 seconds
• --sims 100000 — very accurate, ~50 seconds

Example: python run_predictor.py --sims 100000
Why does France have such a high win probability (32%)? ▼
France is in Group I with Senegal, Iraq, and Norway — a relatively favourable draw. Combined with their very high ELO (1911, the highest of any 2026 team), based on their 2018 WC win, 2022 final runner-up, and recent form boosts, the model places them as clear favourites. The 32% reflects the ELO-based simulated advantage — but note, that still means a 68% chance they don't win!
Why is Italy not in the tournament? ▼
Italy failed to qualify for the 2026 FIFA World Cup through European qualifying. The 48 teams in this predictor are the actual officially qualified teams as of the draw in early 2026.
How do I re-run the model to get fresh predictions? ▼
Simply run the script again — it will overwrite output/predictions.json:

python run_predictor.py --sims 50000

Because the simulation is stochastic (random), results will vary slightly each run. With 50k+ sims, the variance is very small (<0.5% on top teams).
Can I run the Jupyter notebook without running the model first? ▼
Most sections (ELO ratings, historical data, match probabilities) work independently. Section 6 onwards tries to load output/predictions.json — if it's missing, it will automatically run a quick 5,000-simulation demo instead. For full accuracy, run run_predictor.py first.
The dashboard works but probabilities look different from last time I ran it — why? ▼
The Monte Carlo simulation is random, so each run produces slightly different numbers. This is normal and expected — the variance decreases as you use more simulations. At 50,000 sims, top teams should be within ±0.5% of their "true" model probability.
